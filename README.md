# WaveTrace Core
**WaveTrace Research** | `research@wavetrace.tech`

WaveTrace is an open-source browser extension and lightweight Windows companion app designed to make browser-tab music recognition faster and more reliable.

## How It Works
* **Multi-Service Fallback:** Combines Shazam, AcoustID, AudD, and Google Song Search so tracks are still identified when a single service fails or audio samples are short.
* **Windows Companion App:** Handles local audio capture, processing, and recognition offloading outside the browser sandbox.
* **Status:** Currently refactoring the v2.0 extension and companion codebase for faster recognition, lower resource usage, and easier installation.
